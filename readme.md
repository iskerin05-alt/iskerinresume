# Дүйсен Сырым — жеке сайт-портфолио

## Құрылымы
- index.html — басты бет
- about.html — мен туралы
- skills.html — дағдылар
- portfolio.html — курстар мен даму
- contact.html — байланыс
- css/style.css — дизайн және responsive layout
- js/script.js — мобильді мәзір, қараңғы режим, форма тексеруі
- images/profile.jpg — профиль фотосы
- documents/resume.pdf — түйіндеме
- videos/avatar.mp4 — HeyGen бейнесін осы жерге қосу керек

## Netlify-ге жариялау
1. ZIP архивті аш.
2. Netlify аккаунтына кіріп, Add new site → Deploy manually таңда.
3. Ішіндегі `Syrym_Portfolio` бумасының файлдарын drag-and-drop арқылы Netlify deploy аймағына сүйреп апар.
4. Deploy аяқталған соң берілген `netlify.app` URL мекенжайын ашып, 5 бетті тексер.

## Ескерту
Байланыс формасы демонстрациялық, серверге хат жібермейді. HeyGen видеосы videos/avatar.mp4 ретінде қосылған, index.html ішінде видео ойнатқыш дайын.
